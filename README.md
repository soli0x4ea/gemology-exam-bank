# 珠宝鉴定师资格考试题库 · GIC / NGTC / FGA

可交互的珠宝鉴定师（宝石学）资格考试学习题库，覆盖 **GIC（中国地质大学珠宝学院）**、**NGTC（珠宝国检）**、**FGA（英国宝石协会 Gem-A）** 三大体系的核心考点。

> ⚠️ **免责声明**：本题库为**学习辅助题库**，题目由编者依据公开考纲与教材自行编写，**并非官方历年真题**（三大考试的官方真题均不对外公开）。适用于刷考点、熟悉题型、练习中英术语。

## 题库规模

- 共 **198 题**，覆盖 **23 个考点分类**
- 题型：单选题、多选题、判断题、简答题
- 英文题：含 FGA 英文原题，贴合 Gem-A 英文考试风格
- 每题标注适用考试（GIC / NGTC / FGA）、难度、答案与解析

## 在线使用

👉 **GitHub Pages：** https://soli0x4ea.github.io/gemology-exam-bank/

也可直接用浏览器打开本仓库的 `index.html`。交互功能：

- 按 **考试（GIC / NGTC / FGA）**、**分类**、**题型**、**难度** 筛选
- 关键词搜索
- 单题 / 全部显示答案与解析

## 目录结构

| 文件 | 说明 |
|------|------|
| `index.html` | 可交互题库（数据已内联，单文件即可运行） |
| `题库.md` | Markdown 版，便于打印 / 导入笔记软件 |
| `generate_bank.py` | 题库生成器（数据驱动，修改数据后重新生成） |

## 本地重新生成

```bash
python3 generate_bank.py
```
